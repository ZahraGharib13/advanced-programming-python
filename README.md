# Advanced Programming Coursework

A collection of projects and exercises developed during my **Advanced Programming** course using Python.

This repository includes desktop GUI applications, small games, a 3D escape-room project, networking, multiplayer programming, and a geospatial network-analysis project.

## Projects

### 01 — Calculator

A simple desktop calculator built with **Python** and **Tkinter**.

Main concepts:
- GUI programming
- Event handling
- Input validation
- Basic arithmetic operations

Folder:

```text
01-calculator/
```
