# Calculator

A simple desktop calculator built with Python and Tkinter for an Advanced Programming course.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Invalid-input handling
- Reset button

## Requirements

- Python 3
- Tkinter

This project does not require any third-party Python packages, so no `requirements.txt` file is needed.

## Run

```bash
python calculator.py
```

or:

```bash
python3 calculator.py
```
