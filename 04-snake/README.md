# Snake Game

A simple Snake game built with Python and Tkinter.

## Gameplay

Control the snake with the arrow keys, collect the food, and avoid crashing into the walls or the snake's own body.

## Features

- Arrow-key movement
- Random food placement
- Snake growth after eating food
- Wall collision detection
- Self-collision detection
- Game Over message
- Tkinter graphical interface

## Requirements

- Python 3
- Tkinter

This project does not use any third-party Python packages, so no `requirements.txt` file is needed.

## How to Run

Open a terminal in this folder and run:

```bash
python snake.py
```

If your system uses `python3`, run:

```bash
python3 snake.py
```

## Controls

- `Up Arrow` — move up
- `Down Arrow` — move down
- `Left Arrow` — move left
- `Right Arrow` — move right
