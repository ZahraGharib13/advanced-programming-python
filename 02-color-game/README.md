# Color Game

A simple color-matching game built with Python and Tkinter.

## How the Game Works

A color word is displayed in a random font color.
Your task is to type the **color of the text**, not the word itself, and press **Enter**.

The game keeps track of your score during a 60-second countdown.

## Features

- 60-second timer
- Random color words and font colors
- Score tracking
- Keyboard input with Enter
- Start and Reset buttons
- Tkinter graphical interface

## Requirements

- Python 3
- Tkinter

This project does not use any third-party Python packages, so no `requirements.txt` file is needed.

## How to Run

Open a terminal in this folder and run:

```bash
python color_game.py
```

If your system uses `python3`, run:

```bash
python3 color_game.py
```

## Controls

1. Click **Start**.
2. Look at the font color of the displayed word.
3. Type the font color in the input box.
4. Press **Enter** to submit your answer.
5. Click **Reset** to restart the game.
