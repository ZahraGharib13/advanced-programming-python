# Tetris

A desktop Tetris game built with Python and Tkinter.

## Gameplay

Move and rotate falling Tetris blocks, complete full rows, increase your score, and continue until the game ends or the timer reaches zero.

## Features

- Classic Tetris block shapes
- Random block selection
- Random block colors
- Left/right movement
- Rotation
- Faster downward movement
- Collision detection
- Completed-row removal
- Score tracking
- Level tracking
- Countdown timer
- Game Over and Time's Up messages

## Requirements

- Python 3
- Tkinter

This project does not use any third-party Python packages, so no `requirements.txt` file is needed.

## How to Run

Open a terminal in this folder and run:

```bash
python tetris.py
```

If your system uses `python3`, run:

```bash
python3 tetris.py
```

## Controls

- `Left Arrow` — move left
- `Right Arrow` — move right
- `Down Arrow` — increase falling speed
- `Up Arrow` — rotate the current block
